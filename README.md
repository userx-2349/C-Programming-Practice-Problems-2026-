# C Programming Practice Problems (2026)

Welcome to my C programming practice repository! 🚀

This repository tracks my daily coding progress as I revisit C programming from the ground up. I am combining foundational exercises with an intensive refresher to build a deep, low-level understanding of memory, syntax, and system-level concepts.

---

## 🎯 Objectives
* **Rebuild Foundations:** Practice core C syntax, control flow, functions, and standard I/O.
* **Master Low-Level Mechanics:** Tackle pointers, direct memory allocation (`malloc`/`free`), and memory safety.
* **Consistency:** Solve daily practice questions to maintain a continuous coding habit and GitHub streak.
* **Clean Code:** Write idiomatic, readable, and leak-free C code.

---

## 📂 Learning Path & Structure
The repository is organized progressively as I move from basic concepts to advanced implementations:

* `01-basics/` - Data types, operators, conditionals, loops, I/O
* `02-functions-arrays/` - Scope, recursion, multi-dimensional arrays, strings
* `03-pointers-memory/` - Pointer arithmetic, dynamic memory, structs
* `04-data-structures/` - Custom linked lists, stacks, queues, trees
* `05-mini-projects/` - Terminal utilities and small programs

---

## 🛠️ Environment & Tools
* **Language:** C (C11 / C17 standard)
* **Compiler:** GCC / Clang
* **Build System:** Make / CMake
